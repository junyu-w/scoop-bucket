# junyu-w/scoop-bucket

[Scoop](https://scoop.sh) bucket for junyu-w's tools.

```powershell
scoop bucket add junyu-w https://github.com/junyu-w/scoop-bucket
scoop install junyu-w/pipespy
```

| app | description |
| --- | --- |
| [pipespy](https://github.com/junyu-w/pipespy) | TUI that shows the data flowing through every pipe of a shell pipeline |

Manifests are updated automatically by each project's release workflow.
